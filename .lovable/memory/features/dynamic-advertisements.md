---
name: Dynamic advertisements
description: Automatic first-party advertisement placement and preview requirements
type: feature
---
- Ads should appear within article reading flow and available right-side space, not only at the bottom.
- Placement must respond to loaded content, scrolling and screen size without covering article text or controls.
- Select relevant ads using the entry page and browsing interests; keep previews realistic in Advertisement Manager.
- Keep this first-party advertising, not a third-party Google Ads installation.
- Never show advertisements in the header or top-of-page position.
- Show proper display creatives rather than stretched full-width rectangular promotion strips.
- Support multiple uploaded sizes for one advertisement, with accurate admin format previews.
