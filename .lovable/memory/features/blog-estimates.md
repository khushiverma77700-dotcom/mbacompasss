Use supplied reference links first and recent public internet evidence second for missing article details. Changing evidence must have explicit publication/update dates within the last 1–2 months. When direct figures are unavailable, provide clearly labelled approximations with a defensible evidence-based calculation, never invented official facts. Do not show empty/dash table cells or competitor source attribution such as “As per Careers360”; preserve sources privately in the editor report. Do not estimate official deadlines, eligibility rules or rankings as if confirmed.
